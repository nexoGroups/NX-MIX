## NX-MIX 0.3.2-beta.1

- Die Audio-Engine startet automatisch, wenn ein Wiedergabeausgang eingerichtet ist.
- App-Capture erkennt laufende Streams und führt doppelte Programmzuordnungen zusammen. Solange Windows den Stream noch direkt wiedergibt, zeigt NX-MIX den Eingangspegel an und vermeidet eine doppelte Ausgabe.
- Die Einstellungen sind über das Zahnrad oder Strg+8 erreichbar. Der Update-Kanal steht unter **Updates**.
- Die ASIO-Anbindung wurde mit einem Behringer UMC1820 bei 96 kHz im Duplexbetrieb geprüft.
- Diese Beta enthält keinen WaveRT-Treiber. Die fünf nativen Windows-Wiedergabegeräte folgen mit einem separat geprüften Treiberpaket.
