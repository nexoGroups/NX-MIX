## NX-MIX 0.3.3 Beta 2

- Das Beta-Setup und Beta-Updates liefern VB-CABLE von VB-Audio mit. Fehlt der Treiber, öffnet NX-MIX beim ersten Start das Hersteller-Setup. Die Windows-Administratorabfrage und der anschließende Neustart gehören zur Treiberinstallation.
- NX-MIX liest **CABLE Output** direkt als Aufnahmegerät. Wähle für die gewünschten Programme **CABLE Input** als Ausgabe und patche den Eingang **VB-CABLE** in der Matrix auf die gewünschten Ausgänge.
- Eine bereits eingerichtete, kompatible VB-CABLE-Loopback-Zuordnung wechselt bei der ersten Einrichtung auf **CABLE Output** und behält ihre Kanäle und Routen.

VB-CABLE ist Donationware von [VB-Audio](https://vb-audio.com/Cable/). Die Herstellerseite bietet freiwillige Unterstützung und Lizenzen an.
